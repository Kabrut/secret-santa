## 💻 Uruchomienie Lokalne

### 1. Backend (Terminal 1)
```bash
cd backend
npm start
```
✅ Backend dostępny na: http://localhost:5000

### 2. Frontend (Terminal 2)
```bash
cd frontend
npm start
```
✅ Frontend dostępny na: http://localhost:3000

## 📝 Pierwsze Kroki

1. Otwórz http://localhost:3000
2. Przejdź do "Panel Admina"
3. Wprowadź hasło: **swieta2000**
4. Dodaj uczestników (każdy w nowej linii)
5. Ustaw maksymalną kwotę prezentu
6. Zapisz konfigurację
7. Udostępnij link uczestnikom!
